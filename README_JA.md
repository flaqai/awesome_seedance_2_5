## Seedance 2.5 向けの基本構造

公式ページでは、1回で最大30秒の生成、2回の延長、参照動画の意図・構図・映画表現の理解、幅広い音声・映像編集、プロ向けのカメラワーク、演技ブロッキング、ホワイトモデル制御、グリーンバック編集が紹介されています。プロンプトは、形容詞の列ではなく短い演出設計として書くのが効果的です。

```text
[モード] テキスト / 画像 / 参照 / 編集
[目的] 用途、対象、感情、尺、アスペクト比
[素材の役割] 画像1は人物のみ、動画1はカメラ経路のみ参照
[固定要素] 顔、衣装、製品形状、背景、光源、物の数
[時間軸] 導入 -> 主動作 -> 変化 -> 最終画面
[撮影] 画角、カメラ高、移動経路、速度、焦点、停止位置
[演技と物理] 視線、手、重さ、慣性、接触、布、水、煙
[音] セリフ、環境音、効果音、音楽、同期点
[禁止] 変形、重複、手足の追加、偽文字、ロゴ、透かし
```

## コピーできる例：雨のカフェのワンカット

```text
入力画像を唯一のビジュアル基準として使用する。成人の主人公の顔、髪型、紺色のジャケット、テーブル上の物、カフェの配置、朝の主光源を維持する。

12秒の安定したワンカット。コーヒーカップの湯気をマクロで撮影し、カメラはゆっくり引きながら右へ移動する。主人公は本を閉じ、雨の窓を見て、控えめに微笑む。雨粒はガラスを下へ流れ、背景の客は小さく自然に動くだけ。最後は主人公と窓を同時に収めたミディアムショットで完全に停止する。

音は雨、本を閉じる音、カップと受け皿の小さな音、静かな店内環境音のみ。人物の追加、顔や服装の変更、物の増減、手ぶれ、偽の文字、ロゴ、字幕、透かしは禁止。
```

## 画像から動画を作るときの確認事項

- 顔、衣装、製品の形、物の数、構図、主光源を固定する。
- 被写体、環境、カメラの動きを別々に書く。
- 各参照素材には一つだけ役割を与える。
- カメラの開始位置、経路、速度、停止点を明記する。
- 最後の4〜6秒は減速と最終構図に使う。
- 商用利用では、画像・音声・人物・ブランドの権利を確認する。

本リポジトリのプロンプト、シナリオ、説明文、画像は、このコレクションのために新規作成されています。有名人、第三者のブランド文言、既存のキャラクターは使用していません。
